# 鹿港漁人 opener v2 — 台男旁白＋本人畫面（待 YC 點頭再剪）

**產品定位：** NFC 給釣友／朋友「認識他是誰、他在幹嘛、為什麼厲害」——介紹故事，不是空白酷炫廣告。  
**總長目標：** 旁白可念完約 **26–28 秒**（畫面可 28–30s，尾留呼吸）。  
**聲音：** 台灣男生旁白為主（清楚、偏中低音、不廣播腔）＋海浪床＋極輕低沈 BGM；VO 永遠最大。  
**畫面原則：** **爸爸本人優先**；生成只能「同臉／同身形／同裝備／同磯場」延長動作，禁止路人身體。

## 旁白腳本（繁中｜台男語氣｜約 27 秒）

> （語氣：釣友介紹釣友，自豪但不雞湯。可微台語腔，但字用標準繁中。）

**全文（建議一次錄完，剪接時對鏡）：**

「這位，就是鹿港漁人。  
磯上十年，潮汐不等人。  
從鹿港出發，走到卵石堤、走到西岸磯場——  
迴流一送，黑鯛咬在腳邊；  
銀鱗帶水，線還掛在嘴邊。  
他不是來拍照的。  
他是來跟海說話的。  
鹿港漁人。掃進來，認識他。」

**字數／節奏備註：** 約 95–105 字；朗讀目標 26–28s（含句間短停）。  
「這位，就是鹿港漁人。」開場要穩、清楚——認人。  
最後「掃進來，認識他。」對 NFC 場景，短、硬。

### 生成規則（若必須補動作）
- **唯一允許的生成：** 以 `post_older_4`＋dad-catch 幀為 reference 的 image-to-video／角色鎖定，產出「同一人」的上磯、輕拋、持魚轉身。  
- **禁止：** 無參考的路人磯釣男、換臉失敗、裝備品牌亂跳。  
- **生成失敗就改用靜態推鏡／真片放慢**，不要再塞假路人。  
- 建議再從粉專公開貼文多抓 5–10 張「露出同一套裝備／同角度臉」當 ref pack（路徑建議 `/public/media/fb/refs/`）。

### 音訊製作
- VO：edge-tts 或更好的台男聲音（優先 `zh-TW` 男聲，例如 YunJheNeural；若太機器再換本地／錄音）。語速略慢、句尾不要上揚廣告腔。  
- 海浪：`ambient.mp3` 低床。  
- BGM：`bgm-doc.m4a` 壓到 VO 下（約 −18~−22dB relative），中魚句可微起，態度句再壓。  
- loudnorm 以 **VO 清楚** 為準（I≈−16，VO 絕不被音樂蓋）。
