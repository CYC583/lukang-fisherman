# 鹿港漁人 NFC 落地頁 — 設計規格

日期：2026-11-05  
給：YC C（愛爸爸的女兒 C）送給爸爸的禮物站  
部署：Vercel 專案網址 `lukang-fisherman`（`*.vercel.app`，之後可綁自有網域）

## 1. 目標

別人掃爸爸釣具／名片上的 **NTAG216** NFC 後，用手機打開一個很帥、日式職人感的單頁站：

- 一進來就能 **加入鹿港漁人**（Facebook 粉專），不必硬看完故事。
- 想看的人往下看 **互動式漁人故事**（感人＋會笑＋覺得超厲害），故事結束後再出現部落格入口。
- **不寫生日**；頁底署名 `製作人：愛爸爸的女兒C`。
- **只用粉專／痞客邦已公開內容**；不放粉專以外的個資（電話、地址、本名等）。

成功標準：

1. 手機直式優先，3 秒內看得出「鹿港漁人」品牌感。
2. 「加入鹿港漁人」在首屏或開場略過後立刻可見、可點。
3. 故事區有捲動／觸控互動與配樂（可靜音），結束後才推部落格。
4. 部署在使用者的 Vercel 帳號，短網址可寫進 NFC。

## 2. 範圍

### 做

- 單頁 Next.js（App Router）靜態／SSR 皆可，優先靜態輸出以利 Vercel 快取。
- 開場電影感動畫（**可略過**）。
- 捲動視差＋一處輕量互動（如滑／甩拋竿），失敗也能繼續。
- 故事章節（改寫自公開粉專／部落格），可嵌入粉專公開圖／短影片風格動態。
- 背景配樂（可授權／免版稅），預設需使用者手勢後才播放或提供明顯靜音。
- CTA：加入粉專、故事後部落格。
- 頁底署名。

### 不做（本版）

- 登入、留言、後台 CMS。
- 正式自有網域購買（可後補）。
- 爬蟲即時同步粉專（內容先靜態 curation；之後可再加）。
- 寫入或要求任何個資表單。

## 3. 資訊架構（手機直式）

1. **開場（可略過）**  
   紙白／霧金氣氛、海霧礁岩、標題「鹿港漁人」淡入。右上「略過」。

2. **行動首屏**  
   - 主按鈕：**加入鹿港漁人** → `https://www.facebook.com/people/鹿港漁人/100063821466190/`  
   - 次按鈕：**看漁人故事** → 捲到故事錨點 `#story`  
   （朋友掃完可以立刻追蹤，故事之後再看也沒關係。）

3. **故事區 `#story`（互動）**  
   章節建議（皆公開素材改寫，語氣釣友口語＋職人感）：  
   - 與黑鯛對智（觀察像剝洋蔥、餌料進流像放風箏）  
   - 遠征登礁（如東嶼坪／布袋等公開文章）  
   - 現在仍在釣（粉專近況、釣友稱師傅等公開互動，不露個資）  
   可放入：粉專公開圖、紀念意義貼文做成的短動態／影片感剪輯。  
   一處小互動：拋竿手勢成功後解鎖下一段或彩蛋，略過亦可。

4. **故事結束 → 部落格**  
   按鈕：看更多釣行紀錄 → `https://nokia1301471980.pixnet.net/blog`

5. **頁底**  
   `製作人：愛爸爸的女兒C`

## 4. 視覺

- **方向**：日式紙白＋霧金（已選），借鑑 Daiwa／Shimano 日文站的大圖、留白、冷靜專業，不是螢光賽博。
- **色票**：  
  - 紙白 `#F4F1EA`  
  - 深靛 `#0B1C2C`  
  - 炭黑 `#1A1A1A`  
  - 霧金 `#C6A75E`  
  - 海霜 `#7FB8A8`
- **字體**：繁中標題有力、正文清晰可讀；可搭配少量日文假名裝飾但不喧賓奪主。
- **素材**：粉專封面／戰果公開圖（使用前再向 YC 確認授權範圍）；不足處用抽象海霧、礁岩、魚鱗紋。

## 5. 動效與音訊

- 開場 2–3 秒可略過。
- 捲動視差、霧金細線、波紋微動。
- 拋竿小互動＋觸控回饋。
- 配樂：依粉專氛圍選平靜／海風感、免版稅曲；分區可淡入淡出；永遠有靜音鍵；遵守瀏覽器自動播放政策。

## 6. 技術與部署

- Repo／專案名：`lukang-fisherman`
- Stack：Next.js + TypeScript + CSS（或 Tailwind）+ 輕量動畫（CSS／Framer Motion）
- Host：使用者既有 Vercel team（`team_5PjEelQXux3GIeCk4LXY42yE`）新建專案並部署
- NFC：NTAG216 寫入 HTTPS 正式網址即可；檔案大小不成問題
- 隱私／法遵：不蒐集個資；外連僅粉專與部落格；圖片標註來源為公開粉專／部落格

## 7. 文案語氣

- 繁體中文；釣友口語；感人但不矯情；讓爸爸會笑、讓朋友覺得他超厲害。
- 不寫生日、不寫粉專未公開的個資、不擅自放釣友真實全名（部落格暱稱先省略或經 YC 同意）。

- 確認配樂最終曲目。
