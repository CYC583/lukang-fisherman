# 鹿港漁人 (lukang-fisherman)

Mobile-first gift landing page (Next.js + Tailwind + Vitest).

- `npm run dev` — dev server
- `npm test` — vitest
- Design tokens: `src/styles/tokens.css`

## 配樂（Ambient audio）

- `public/media/ambient.mp3`：目前為**佔位**——用 ffmpeg 合成的 30 秒低通棕噪音「海浪感」循環（原創，無授權問題）。
- 正式 BGM 之後會換成免版稅／可商用曲目，直接覆蓋同檔名即可。
- 行為：預設靜音、不自動播放；右下角按鈕點一下才播放（音量 0.35），再點關閉。
